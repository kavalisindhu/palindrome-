A palindrome is a word, number, or string that reads the same forward and backward.

Examples:

madam → Palindrome
level → Palindrome
121 → Palindrome
hello → Not a palindrome
How It Works

The program checks whether a given string is a palindrome by comparing characters from both ends.

Take a string as input.
Compare the first character with the last character.
Compare the second character with the second-last character.
Continue until the middle of the string.
If all characters match, the string is a palindrome.
Otherwise, it is not a palindrome.
Example

Input:

madam

Output:

Palindrome
Technologies Used
Java
Scanner for user input
How to Run

Compile the program:

javac Palindrome.java

Run the program:

java Palindrome
